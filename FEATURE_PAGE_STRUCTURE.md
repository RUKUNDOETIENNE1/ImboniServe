## Navigation Structure

```
Homepage
├── Features (dropdown)
│   ├── Operations → /features/operations
│   ├── AI → /features/ai
│   ├── Analytics → /features/analytics
│   ├── Finance → /features/finance
│   ├── Growth → /features/growth
│   └── Infrastructure → /features/infrastructure
├── Pricing → /pricing
├── Discovery → /discover
└── Get Started → /auth/signin
```

Each feature page follows the same pattern:
1. **Hero** — one Tier 1 capability with visual
2. **Featured** — 2-4 Tier 1 or Tier 2 capabilities with descriptions
3. **Standard grid** — Tier 3 capabilities with brief descriptions
4. **Footer** — Tier 4 capabilities with one-line mentions (if any)
