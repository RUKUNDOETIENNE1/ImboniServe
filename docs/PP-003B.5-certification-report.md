## 1. Summary

The Operations Intelligence Workspace is the operational command center for investigating, explaining, and resolving every important event in the Partnership Operating System. It provides a unified workspace with 10 sections, a composite API route, and 11 reusable components.

**Route:** `/admin/operations-intelligence`  
**API:** `/api/admin/operations-intelligence` (GET + PATCH)

## 4. Architecture Decisions

- **Composite API:** Single endpoint aggregates all 10 sections to avoid waterfall requests. GET returns all data; PATCH handles resolution actions.
- **Component reuse:** No duplicated investigation logic. All data access goes through existing services and Prisma models.
- **Tabbed Timeline/Audit:** Reduces vertical scroll while keeping both accessible.
- **Entity-scoped sections:** Journey + Financial Trace appear only when an entity is selected, reducing initial cognitive load.
- **Exception detection:** Computed in real-time from database queries (missing attribution, duplicate attribution, expired codes, missing commissions, stalled campaigns, inactive partners).
