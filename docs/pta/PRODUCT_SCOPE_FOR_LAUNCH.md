# Product Scope for Launch — Version 1.0

**Platform:** ImboniServe  
**Date:** July 26, 2026  
**Document Type:** Version 1.0 Product Scope Definition  

---

## 1. Purpose

This document defines exactly what ImboniServe Version 1.0 includes. Everything outside this scope moves to future releases. This is the authoritative reference for what a restaurant receives on day one.

---

## 2. The Day-One Question

> "If a restaurant signs up today, what exactly will they receive on day one?"

### Answer

A restaurant that signs up for ImboniServe Version 1.0 receives:

**A complete restaurant operations platform** with QR code ordering, kitchen display, table management, reservations, menu management, inventory tracking with AI-powered reorder alerts, mobile money payments (MTn MoMo, Airtel Money, IremboPay), WhatsApp notifications, staff management with role-based access, daily reports and Z-Report, QR code generation and analytics, and a customer referral program — all manageable from a single dashboard.

## 5. What Is NOT in Version 1.0

The following features are explicitly excluded from Version 1.0 and must not be marketed as available:

- Site Builder
- Hotel Mode
- AI Menu Builder (OCR-based menu creation)
- WhatsApp Campaigns
- Menu A/B Testing
- Voice Ordering (WhatsApp AI)
- Reservation Deposits
- CRM (RFM Segmentation) — available as Early Access by request
- Loyalty & Rewards — available as Early Access by request
- Promotions & Happy Hours — available as Early Access by request
- AI Insights Dashboard — available as Early Access by request
- Supplier Marketplace — Coming Soon
- Recipe Management with Costing (full workflow)
- Prep Plans & Forecasting
- White-Label Options
- API Access
- Custom Integrations
- SSO (Single Sign-On)
- On-Premise Deployment
- Regional Data Residency
- Card / POS Payments
