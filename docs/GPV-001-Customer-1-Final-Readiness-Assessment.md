## What Works End-to-End

The following business journeys have been verified working:

1. **Signup → MFA Login → Dashboard** — User registration, OTP-based MFA, dashboard access
2. **Menu Management** — CRUD operations on menu items
3. **QR Ordering → Kitchen → Payment → Dashboard** — Order creation, kitchen dispatch, payment processing, revenue display
4. **Financial Reconciliation** — Sale = Ledger = Dashboard = CloseDay = CEO (0 variance)
5. **Inventory Management** — CRUD, stock adjustments, low stock alerts
6. **Supplier Orders** — Creation, listing, status transitions, delivery confirmation, BigInt serialization
7. **Reservations** — Create, assign table, confirm (with table auto-reserve), complete (with table release), cancel, no-show (with forfeit)
8. **Close-Day** — Z-Report GET (reservations + financials), close-day POST, audit log, double-close prevention, ledger cross-check
9. **Tax Configuration** — Country defaults (RW/UG/TZ = INCLUSIVE), settings sync, both EXCLUSIVE and INCLUSIVE calculation modes

## Known Limitations (Non-Blocking)

1. **Email Delivery** — The test email domain (`imboniserve-test.com`) doesn't exist, so OTP emails are not deliverable. DB-backed OTP retrieval works for automated verification. Production deployment must use a real email service.

2. **WhatsApp OTP** — Twilio WhatsApp channel is not configured (error 63007). Email OTP works. Production deployment must configure Twilio WhatsApp.

3. **QR Token Signature** — The test QR token has an invalid signature (JWT secret may have changed). New QR tokens generated by the system will work correctly. Existing test tokens need regeneration.

4. **TaxConfiguration Dead Code** — `TaxService.calculateTaxes()` is defined but never called. All production tax calculations use `business.taxMode` inline. This is documented but not removed (larger refactor outside GPV-001 scope).

5. **Existing Business Tax Mode** — Existing businesses (Nyama Cafe Kigali, ICTHubs, GPV Test Restaurant) still have `taxMode: EXCLUSIVE` in the DB. New signups default to INCLUSIVE for RW/UG/TZ. Existing businesses can change via settings.

## Recommendations for Customer #1 Onboarding

1. **Configure real email service** — Set up SendGrid, AWS SES, or similar for OTP delivery
2. **Configure Twilio WhatsApp** — Set up Twilio WhatsApp Business channel for WhatsApp OTP
3. **Confirm tax mode** — Customer #1 should confirm whether their menu prices include VAT (INCLUSIVE) or exclude VAT (EXCLUSIVE), and set accordingly via settings
4. **Generate fresh QR codes** — Regenerate QR codes for tables to ensure valid token signatures
5. **Run production build** — Use `npm run build && npm start` for production, not `npm run dev`
