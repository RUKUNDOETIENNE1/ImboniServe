# PP-003B.5 — Changelog

## [PP-003B.5] - 2026-08-01

### Added
- **Operations Intelligence API Route** (`src/pages/api/admin/operations-intelligence/index.ts`)
  - GET endpoint aggregating: universal search, operations timeline, attribution explorer, customer journey, financial trace, campaign intelligence, audit center, exception detection, system health signals
  - PATCH endpoint for resolution actions: approveCommission, validateCommission, triggerPayout, pauseCampaign, resumeCampaign, extendTrial, addInternalNote, assignInvestigation
  - Session-based auth with role gating (11 read roles, 5 action roles)
  - Rate limited at 100 req/min

- **Operations Intelligence Workspace Page** (`src/pages/admin/operations-intelligence.tsx`)
  - Single-view workspace with all 10 sections
  - SSR with `getServerSideProps` session + role check
  - Tabbed Timeline/Audit Center
  - Entity-scoped Journey + Financial Trace sections
  - Loading, error, and empty states

- **Reusable Components** (in `src/components/partnerships/`)
  - `InvestigationSearch.tsx` — Universal search with typed results
  - `JourneyExplorer.tsx` — Business lifecycle visualization
  - `AttributionGraph.tsx` — Multi-touch attribution display
  - `FinancialTrace.tsx` — Revenue → Commission → Payout → Audit flow
  - `OperationsTimeline.tsx` — Chronological event feed with pagination
  - `AuditExplorer.tsx` — Filterable audit records with pagination
  - `ExceptionPanel.tsx` — Detected anomalies sorted by severity
  - `ResolutionPanel.tsx` — Contextual action buttons with permission gating
  - `SystemHealthWidget.tsx` — Health score + individual signal metrics
  - `RelationshipGraph.tsx` — Upstream/downstream entity relationships
  - `CampaignIntelligence.tsx` — Campaign performance with progress bars

- **Navigation** — Added "Operations Intelligence" entry to AdminLayout with Radar icon

- **Tests** (`tests/components/operations-intelligence.test.tsx`)
  - 78 tests covering all components, accessibility, and regression scenarios

- **Documentation** — Certification report and changelog
