# Operations Intelligence Workspace — Standard Operating Procedure

## Purpose
The Operations Intelligence Workspace is the operational command center for investigating, explaining, and resolving every important event in the Partnership Operating System.

## Access
- **URL:** `/admin/operations-intelligence`
- **Required roles:** ADMIN, FINANCE, CFO, PARTNERSHIP_MANAGER, OPERATIONS_MANAGER, CEO, SUPPORT, LEGAL, EXECUTIVE, MARKETING, SALES
- **Resolution roles (PATCH actions):** ADMIN, FINANCE, CFO, OPERATIONS_MANAGER, SUPPORT

## Investigation Workflow

### 1. Universal Search
1. Enter a search query (minimum 2 characters) in the search bar
2. Press Enter to search across: businesses, partnerships, codes, campaigns, commissions, payouts, applications, agreements
3. Click any result to load entity-specific sections (Journey + Financial Trace)

### 2. System Health Signals
- Review the overall health score at the top
- Check individual signals for attribution, campaign, and revenue health
- Scores below 50 indicate critical issues requiring attention

### 3. Exception Investigation
- Exceptions are auto-detected and sorted by severity (high → medium → low)
- Each exception shows: title, description, cause, recommendation, affected entities
- Click "Resolve" to take action directly from the exception (requires resolution permissions)

### 4. Customer Journey Explorer
- Appears when a business entity is selected from search
- Shows chronological lifecycle: Signup → Attribution → Code Redemption → Trial → Approval → Subscription → Revenue → Commission
- Each step shows timestamp, status, and contextual details

### 5. Financial Trace
- Appears when an entity is selected
- Shows the complete financial flow: Revenue → Commission → Payout → Audit
- Includes ledger entries, commission records, payout records, and audit trail

### 6. Attribution Explorer
- Displays all attribution touches across the system
- Canonical attribution is highlighted with green border
- Shows source type, touch type, code, and UTM parameters

### 7. Campaign Intelligence
- Lists all campaigns with performance metrics
- Shows signup/conversion progress bars against targets
- Displays revenue, budget, code count, and commission count

### 8. Operations Timeline
- Chronological feed of all partnership events
- Paginated (50 per page)
- Filterable by entity via search

### 9. Audit Center
- Immutable audit records showing data-level changes
- Filterable by action type
- Shows actor, old value, new value, and timestamp

### 10. Resolution Center
- Available actions: Validate Commission, Approve Commission, Trigger Payout, Pause Campaign, Resume Campaign, Extend Trial, Add Internal Note, Assign Investigation
- Actions are disabled if user lacks resolution permissions
- Entity-specific actions require an entity to be selected from search

## Resolution Actions Reference

| Action | Required Fields | Effect |
|---|---|---|
| validateCommission | commissionId | Moves commission PENDING → VALIDATED |
| approveCommission | commissionId | Moves commission VALIDATED → APPROVED |
| triggerPayout | partnershipId, amountCents, method | Creates new payout request |
| pauseCampaign | campaignId | Sets campaign status to PAUSED |
| resumeCampaign | campaignId | Sets campaign status to ACTIVE |
| extendTrial | businessId, additionalDays | Extends business trial end date |
| addInternalNote | partnershipId, note | Logs internal note to activity log |
| assignInvestigation | partnershipId, assignedTo, reason | Assigns investigation to a user |

## Best Practices
- Always start with Universal Search to scope your investigation
- Check System Health before diving into specific issues
- Review Exceptions first — they highlight the most critical operational issues
- Use the Financial Trace to verify any monetary discrepancy end-to-end
- Cross-reference Timeline events with Audit records for complete explainability
- Add internal notes when closing an investigation for future reference
